GoodTracker – Team Agreement

1. Purpose

This agreement defines how the GoodTracker project team will work together, communicate, share responsibilities, and manage project tasks.

2. Team Members and Roles

Team Member	Main Responsibility
Talha Yılmaz	Mobile UI and navigation
Eylül Melda Çakmak	Mobile API integration and acceptance checks
Kerem Tuna	Database and equipment API
Kardelen Darğın	Reservation API and project tracking

Testing and documentation are shared responsibilities.

3. Working Rules

* Each team member is responsible for completing assigned tasks.
* Tasks must have a clear owner and expected result.
* Team members should inform the group about delays or blockers.
* All members should contribute to project documentation and reviews.
* Work should be planned according to the agreed project schedule.

4. GitHub Workflow

* Each member should work on a separate branch.
* Changes should be submitted through Pull Requests.
* Another team member should review the Pull Request.
* Commit messages should clearly describe the changes.
* The project board should be updated regularly.

5. Code Review

* Team members should review each other’s contributions.
* Reviewers should check correctness, readability, and consistency.
* Requested changes should be addressed before merging.
* Important issues should be discussed with the team.

6. Communication Rules

* GitHub Issues and Projects will be used for task tracking.
* Team members should communicate blockers as soon as possible.
* Important decisions should be shared with the whole team.
* Meeting notes and decisions should be documented when necessary.

7. Decision Making and Conflict Resolution

* Team decisions should be discussed together.
* Different opinions should be evaluated respectfully.
* If an agreement cannot be reached, the team should discuss the alternatives and choose the most suitable solution.

8. Definition of Done

A task is considered complete when:

* The expected result has been achieved.
* The work has been reviewed by another team member when applicable.
* Relevant documentation has been updated.
* The Pull Request has been accepted and merged.
* The project board status has been updated.

9. Agreement

All team members are expected to follow these working agreements throughout the GoodTracker project.
